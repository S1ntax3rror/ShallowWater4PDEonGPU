# Cleuson input data

Generated by `examples/cleuson/prepare_terrain.py`. See
[`docs/cleuson_dam_break.md`](../../docs/cleuson_dam_break.md) for sources,
assumptions, solver settings and reproduction instructions.

`terrain.bin` is averaged swissALTI3D terrain. `bed_before.bin` and
`bed_after.bin` include idealized lake bathymetry and the dam footprint.
`h_initial.bin` is the stationary reservoir depth; `reservoir_mask.bin`
and `dam_mask.bin` contain 0/1 masks. All six files are little-endian Float64,
x-fast, with dimensions and cell bounds defined in `case.toml`.

`lake.geojson` is the FOEN lake-inventory response in LV95 coordinates.
`sources.json` records the original download URLs and tile checksums.
